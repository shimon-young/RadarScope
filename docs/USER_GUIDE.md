# RadarScope 用户手册

RadarScope 是阿里达摩院 DAMO RADAR 腹部增强 CT 多病症筛查模型的本地桌面应用。
输入腹部 CT（NIfTI 格式），输出 146 项「器官_病症」阳性概率与 36 类器官分割掩膜，
全程本地推理，**运行期不访问外网**，仅供科研/辅助阅片，非临床诊断依据。

---

## 1. 启动

### 前置条件
- NVIDIA GPU（推荐 8 GB 以上显存）或纯 CPU 模式（速度较慢）
- 已完成环境安装与权重下载（见《部署与离线说明》`DEPLOY_OFFLINE.md`）

### 启动命令

```bash
cd RADAR_inference

# 局域网模式（默认，0.0.0.0，网内其他设备可通过本机 IP 访问）
python service.py --host 0.0.0.0

# 单机模式（仅本机 127.0.0.1 可访问）
python service.py

# 自定义端口 / 产物目录
python service.py --host 0.0.0.0 --port 8125 --results-dir D:/radar_results
```

启动后用浏览器打开提示的地址（默认 `http://127.0.0.1:8000`），即为应用主界面。

> 局域网模式下，界面会提示「当前处于局域网模式」；数据仍在服务端所在机器上处理。

### 一键脚本（推荐）

`RADAR_inference/deploy/` 提供跨平台启停脚本，开发仓库与打包后的绿色目录通用：

```bat
deploy\start_server.bat           REM 局域网模式（默认，0.0.0.0:8125）
deploy\start_server.bat local     REM 单机模式：127.0.0.1:8125，自动打开浏览器
deploy\start_server.bat local 9000 REM 单机模式 + 自定义端口
deploy\stop_server.bat            REM 停止服务（默认端口 8125）
```

Linux 使用 `./deploy/start_server.sh` / `./deploy/stop_server.sh`。服务端一个包、客户端即浏览器：
局域网内任何电脑（含个人电脑）无需安装任何东西，浏览器访问 `http://<服务器IP>:8125` 即可使用。
脚本细节、Python 环境解析顺序与开机常驻（NSSM/systemd）方案见 `deploy/README.md`。

## 2. 界面与操作

界面分三栏：**左栏**（上传、参数、历史任务、分析结果）、**中间**（MPR 三视图）、**顶部**（系统状态）。

### 2.1 上传影像
1. 点击「选择影像」或把 `.nii.gz` / `.nii` 文件拖入；
2. 影像会**立即在中间三视图解码显示**（轴位/冠状位/矢状位）；
3. 推荐门脉期增强 CT，但软件不做强制校验。

### 2.2 开始分析
- 选择模型：**main**（146 项标准模型）/ **plus**（20 项 Merlin 精调项）；
- 选择精度：GPU 下默认 **bf16**（最快），可选 fp16 / fp32；CPU 仅 fp32；
- 设备：auto（默认自动选 GPU）/ cpu；
- 点击「开始分析」，进度条实时显示预处理 → 滑窗推理 → 后处理各阶段。

### 2.3 查看结果
结果出现在**左栏结果卡**，按部位（器官）分组、组间按最高概率降序：
- **统计条**：阳性项数 / 最高概率 / 总条目 / 耗时；
- **本地阈值**滑块：默认 0.5，调整后阳性判定与列表即时更新（仅影响前端显示，不影响已保存结果）；
- **筛选**：仅阳性 / 全部条目，支持按器官或病症搜索；
- **点击任一病症条目** → 三视图自动定位到该器官掩膜体素上（十字线落在器官内），且单独高亮该器官掩膜；
- **导出**：CSV（逐项概率）、原始 JSON、整包导出（zip 含结果 CSV 与元数据）；原始影像、分割掩膜与日志不提供导出。

### 2.4 图像工具
- 工具栏可切换：窗宽窗位（默认）/ 平移 / 缩放 / 层面滚动 / 十字线；
- **十字线**：三视图联动层面定位，切换病例后依然可用；
- **图例**（器官列表）：点击某器官可单独显示/隐藏其掩膜；
- **叠加显示**开关：整体显示/隐藏分割掩膜；
- **透明度**滑块：调整掩膜叠加浓淡。

### 2.5 历史任务
- 左栏历史列表展示最近任务（默认保留 7 天，可配置）；
- 点击任一历史任务可完整回看影像 + 掩膜 + 结果；
- 「刷新」重新拉取列表；删除按钮可清理单个任务（正在运行的任务先取消再删）。

## 3. 参数与文件说明

| 项 | 说明 |
| --- | --- |
| 阈值（threshold） | 提交任务时的默认阳性阈值（0–1），后续可在结果区随时调整 |
| 保存掩膜 | 关闭后不落盘分割掩膜文件，节省磁盘 |
| 任务产物 | `results/jobs/<任务ID>/`：result.json、结果 CSV、日志、（可选）segmentation.nii.gz、原始输入 |
| 保留策略 | 默认 7 天自动清理，可用 `RADAR_RETENTION_DAYS` 调整 |

主要环境变量（也可用命令行参数替代）：`RADAR_HOST` / `RADAR_PORT` / `RADAR_RESULTS_DIR` / `RADAR_MAX_UPLOAD_MB` / `RADAR_MAX_JOBS`。

## 4. 常见问题与错误处理

| 提示 | 含义与处理 |
| --- | --- |
| **GPU 显存不足** | 精度改 fp32/fp16；设备改用 CPU；或关闭其他占用显存的程序后重试 |
| **系统内存不足** | 关闭其他大型程序；或改用 CPU 模式（峰值内存更低） |
| **磁盘空间不足（507）** | 清理 `results/` 目录或更换 `--results-dir` 后重试 |
| **不支持的文件格式（415）** | MVP 仅支持 NIfTI（`.nii.gz`/`.nii`），DICOM 支持在后续版本 |
| **权重缺失** | 按 `/api/system` 中 weights 提示补齐模型权重文件 |
| **分析卡住/进度不动** | 结果接口有终态轮询兜底；若长时间无进展，查看任务日志（结果卡「日志」链接） |
| **图像/十字线异常** | 强制刷新浏览器（Ctrl+F5）重建视图 |

## 5. 安全与隐私
- 全程本地推理，运行期零外网连接（可用 `scripts/netprobe.py` 自行验证）；
- 服务默认绑定 `0.0.0.0`（局域网模式，无鉴权），**请只在可信网络内使用**；若仅本机使用请显式单机模式 `start_server.bat local`（绑定 127.0.0.1）；
- 接口对任务 ID 做格式白名单校验，跨文件访问不可利用；
- 本软件输出仅供科研/辅助阅片，**不能替代医生诊断**。
